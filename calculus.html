规律已经出现：允许的误差越小，就需要从越后面开始看。但无论要求多严格，总能找到这样一个开始位置。

历史小注：19 世纪，数学家逐渐用 ε 语言取代“无限接近”这类直观说法，极限才有了今天的严格定义。

第一章 · 函数与极限
数列极限 · 把规律写成定义

ε–N 语言给出了准确描述

把“允许的误差”统一记作 ε，把“从这里开始”记作 N。数列极限的定义是：

对任意 ε > 0，都存在正整数 N，使得当 n > N 时，

|aₙ − L| < ε

那么称数列 aₙ 收敛到 L，记作 limn→∞ aₙ = L。

这串符号只表达一件事：无论允许的误差多小，数列的整个尾部最终都能进入这个误差范围。

第一章 · 函数与极限
数列极限 · 逐句读懂

定义中的三个量词分别在说什么？

任意 ε > 0

无论允许的误差有多小。

存在 N

总能找到一个开始位置；N 可以随 ε 改变。

任意 n > N

从 N 后面开始的每一项，而不是其中几项。

数列：aₙ = 1/n，极限：L = 0

拖动 ε 后，原来的 N 可能不再满足要求；但总能把 N 向后移动，直到整个尾部进入误差范围。

第一章 · 函数与极限
数列极限 · 用定义排除假象

为什么“大多数项接近 0”还不够？

因为定义要求的是所有 n>N。如果无论 N 取多大，后面仍有尖峰落在 ε 范围之外，那么这个数列就不收敛到 0。

“从某处以后都成立”不同于“以后经常成立”。前者要求所有后续项都满足条件。

第一章 · 函数与极限
函数极限 · 把规律写成定义

函数极限的 ε–δ 定义

如果对于任意 ε > 0，都存在 δ > 0，使得只要

0 < |x−a| < δ

就有 |f(x)−L| < ε，那么 limx→af(x)=L。

为什么写 0<|x−a|？

它排除了 x=a。极限研究的是 a 附近的趋势，不要求函数在 a 有定义。

δ 是固定的吗？

不是。ε 越小，通常要选择更小的 δ。δ 可以依赖 ε。

任意 ε，是读者提出要求；存在 δ，是函数必须给出的回答。

连续性 · 三个条件缺一不可

连续，就是极限与函数值接上了

函数 f 在 x=a 处连续，需要同时满足三件事：

① 点上有值
f(a) 存在
② 附近有趋势

③ 两者相等
limx→af(x)=f(a)
limx→af(x)=f(a)

这条等式很短，但它已经包含“点上有值、极限存在、两者相等”。

极限只看附近；连续还要求附近的趋势准确落到这个点上。

用定义算一次

为什么 x² 的导数是 2x？

① 写差商：［(x+h)²−x²］/h
② 展开并约去 h：［2xh+h²］/h = 2x+h
③ 令 h→0：2x+h → 2x
如果 f(x)=x²，那么 f′(x)=2x

这不是由图像“猜”出来的，而是从导数定义推出的。

在 h→0 的过程中，h 始终不是 0，所以可以先约去 h，再取极限。

第三章 · 积分
第一节 · 先从面积问题开始

不会算曲边面积，就先用长方形铺满它

每个长方形的面积是“宽 × 高”。把所有长方形面积相加，就得到曲边面积的近似值。

近似面积 = Σ f(xᵢ*)Δx

关键不在于长方形，而在于：切小、近似、相加，再让小块无限变细。

第三章 · 积分
第二节 · 定积分的定义

把“无限细以后再相加”写成极限

把 [a,b] 分成许多小区间，宽度记作 Δxᵢ，在第 i 段选一点 xᵢ*。若和式的极限存在，就定义：

∫ab f(x)dx = lim Σ f(xᵢ*)Δxᵢ
f(xᵢ*)

第 i 个小块的近似高度。

Δxᵢ

第 i 个小块的宽度。

Σ 与极限

先把小块相加，再让最宽的小块也趋近 0。

积分符号 ∫ 是拉长的字母 S，来自“求和”一词。它提醒我们：积分本质上是连续的加法。

第三章 · 积分
第三节 · 不定积分

如果知道变化率，能找回原函数吗？

求导把函数变成变化率。现在反过来问：

谁的导数是 2x？
(x²)′=2x
(x²+7)′=2x

常数求导后都会消失，因此答案不止一个。

若 F′(x)=f(x)，就称 F 是 f 的一个原函数。所有原函数写作：

∫f(x)dx=F(x)+C

不定积分末尾的 +C 不是装饰，它代表求导过程中丢失的任意常数。

第三章 · 积分
第四节 · 微积分基本定理

面积问题，为什么最后变成了找原函数？

定义累积面积函数：

A(x)=∫axf(t)dt

把右端点从 x 增加到 x+h，新增加的是一条很窄的面积：

当 h 很小时，新增面积约为 f(x)h，所以面积的瞬时变化率就是 f(x)：

A′(x)=f(x)

求导与积分在这里成为互逆过程。

第三章 · 积分
基本定理的计算形式

找到一个原函数，就能计算定积分

若 F′(x)=f(x)，那么：

∫abf(x)dx=F(b)−F(a)

例如：

① 求原函数：∫x²dx=x³/3+C
② 代入上限：F(1)=1/3
③ 减去下限：F(0)=0
∫01x²dx=1/3

黎曼和告诉我们积分是什么；基本定理告诉我们怎样高效地算。

第三章 · 积分
第六节 · 积分描述累积

速度累积成路程，流量累积成总量

已知速度 v(t)

位移=∫t₁t₂v(t)dt

每个极短时间内的位移约为 v(t)dt，把它们加起来得到总位移。

已知密度 ρ(x)

总质量=∫ρ(x)dx

每个极短区间内的质量约为 ρ(x)dx，把它们加起来得到总质量。

积分不只是在算面积。面积只是“局部量 × 小宽度再累加”的第一幅图。
