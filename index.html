FUNCTION VALUE ≠ LIMIT

函数值与极限

基础 · 高频
读图函数值双侧极限

图中 f(1)=4，求 limx→1 f(x)。

先遮住那个实心点，只看曲线从左右两边要去哪里。

逐步解析0 / 5
  1. 1从左侧靠近 1，图像沿直线靠近 y=2。
  2. 2从右侧靠近 1，也靠近 y=2。
  3. 3两侧目标相同；点上的 f(1)=4 不参与这次投票。
  4. 4答案：limx→1 f(x)=2
  5. ✓一句话记住：极限看附近，函数值看当天。
14
ONE-SIDED LIMITS

左极限与右极限

基础 · 必考
左右极限存在性

根据图像，判断 limx→0 f(x) 是否存在。

双侧极限成立，需要左右两边给出同一个答案。

逐步解析0 / 5
  1. 1左侧靠近 0 时，函数值靠近 1。
  2. 2右侧靠近 0 时，函数值靠近 3。
  3. 31≠3，左右极限不相等。
  4. 4答案：双侧极限不存在。
  5. ✓一句话记住：左右必须碰头，双侧极限才存在。
15
REMOVABLE DISCONTINUITY

可去间断点

基础 · 高频
0/0 型因式分解可去间断

求 limx→1 (x²−1)/(x−1)。

代入得到 0/0，只说明“现在还不能直接算”。

逐步解析0 / 5
  1. 1分子分解：x²−1=(x−1)(x+1)。
  2. 2在 x≠1 的附近，可约去 x−1。
  3. 3原式在 1 附近与 x+1 完全相同。
  4. 4答案：limx→1 (x²−1)/(x−1)=2
  5. ✓一句话记住：一个空洞拦不住附近的趋势。
16
CONTINUITY PARAMETER

用连续性确定参数

进阶 · 高频
分段函数连续参数

设 f(x)=ax+1 (x<2)，f(x)=x²−a (x≥2)。若 f 在 x=2 连续，求 a。

连续就是：左边靠近的高度＝右边靠近的高度＝点上的高度。

逐步解析0 / 5
  1. 1左极限：2a+1。
  2. 2右极限与函数值：4−a。
  3. 3连续要求 2a+1=4−a。
  4. 4答案：a=1。
  5. ✓一句话记住：分段函数连续，先把接口两端焊平。

RATIONALIZATION

根式极限与有理化

基础 · 高频
根式有理化0/0 型

求 limx→1 √(x+3)−2x−1。

遇到“两个根式相减”，共轭通常就在门口等你。

逐步解析0 / 5
  1. 1分子分母同乘 √(x+3)+2。
  2. 2新分子变成 (x+3)−4=x−1。
  3. 3约去 x−1，剩下 1√(x+3)+2。
  4. 4答案：代入得 1/4。
  5. ✓一句话记住：0/0 是路牌，不是终点。
18
LOCAL LINEARITY

三角函数的等价无穷小

进阶 · 高频
等价无穷小局部线性

求 limx→0 sin(3x)/tan(2x)。

在 0 附近，先把曲线当作自己的切线。

逐步解析0 / 5
  1. 1当 x→0，有 sin(3x)∼3x。
  2. 2同时 tan(2x)∼2x。
  3. 3原比值与 3x/(2x) 有相同极限。
  4. 4答案：3/2。
  5. ✓一句话记住：靠近 0，常见三角函数先亮出线性底牌。
19
SQUEEZE THEOREM

用夹逼定理求极限

进阶 · 经典
夹逼定理振荡估计

求 limx→0 x²sin(1/x)。

算不出 sin(1/x) 的走向，就控制它能跑多远。

逐步解析0 / 5
  1. 1因为 −1≤sin(1/x)≤1。
  2. 2乘以非负的 x²：−x²≤x²sin(1/x)≤x²。
  3. 3上下两堵墙在 x→0 时都趋向 0。
  4. 4答案：由夹逼定理，极限为 0。
  5. ✓一句话记住：振荡不可怕，只要振幅缩到零。
20
INFINITE LIMITS

无穷极限的左右方向

基础 · 易错
无穷极限单侧方向

判断 limx→1 1/(x−1) 是否存在。

“绝对值都很大”还不够，方向也必须一致。

逐步解析0 / 5
  1. 1x→1⁻ 时，分母是很小的负数，所以趋向 −∞。
  2. 2x→1⁺ 时，分母是很小的正数，所以趋向 +∞。
  3. 3左右方向相反，不能合并成一个双侧极限。
  4. 4答案：双侧极限不存在。
  5. ✓一句话记住：正无穷和负无穷不是“差不多”。
